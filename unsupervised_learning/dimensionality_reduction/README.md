# Dimensionality Reduction

Reducing the number of features of a dataset with PCA and t-SNE, using numpy.

## Tasks

| File | Description |
| --- | --- |
| `0-pca.py` | `pca(X, var=0.95)`: returns the weights matrix `W` that keeps `var` fraction of the variance of `X` |
| `1-pca.py` | `pca(X, ndim)`: centers `X` and returns its projection `T` of shape `(n, ndim)` |
